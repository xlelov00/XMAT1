# XMAT1 – príprava na test

Statické študijné stránky fungujú v prehliadači aj bez zostavovania projektu.

- `index.html` presmeruje na interaktívneho sprievodcu.
- `Source/xmat1-krok-za-krokom.html` obsahuje lekcie a precvičovanie.
- `Source/priprava-xmat1.html` obsahuje prehľad tém a pokynov.
- Originálne PDF a textové študijné podklady zostávajú v lokálnom priečinku `Prilohy/XMAT1`.

## GitHub Pages

Po nahraní súborov na GitHub otvor **Settings → Pages**. V časti **Build and deployment** zvoľ **Deploy from a branch**, vyber vetvu `main`, priečinok `/ (root)` a ulož nastavenie. GitHub po zverejnení zobrazí adresu stránky. Pri štandardnom nastavení repozitára je očakávaná adresa `https://xlelov00.github.io/XMAT1/`.

Online sú iba vlastné študijné stránky; pôvodné dokumenty ostávajú lokálne.
