1. Matice – postupy a počítanie

Rozmery: A typu m×n má m riadkov a n stĺpcov. A+B existuje len pri rovnakých rozmeroch. AB existuje, keď počet stĺpcov A = počet riadkov B; výsledok má rozmery m×p. Pri výpočte AB násobíme riadok A stĺpcom B.

1.1 Sčítanie a násobenie skalárom

A = [ 1  −2  3 ]     B = [ 3  1 −1 ]
    [−2   0  1 ]         [ 0  9 −3 ]
Vypočítaj A+B a 2A−B.
Postup a riešenie

Sčítame prvky na rovnakých pozíciách. Pri 2A−B najskôr vynásobíme každý prvok A číslom 2 a potom odčítame príslušný prvok B.

A+B  = [ 1+3  −2+1   3−1 ] = [ 4 −1  2 ]
       [−2+0   0+9   1−3 ]   [−2  9 −2 ]
2A−B = [ 2−3  −4−1   6−(−1) ] = [−1 −5  7 ]
       [−4−0   0−9   2−(−3) ]   [−4 −9  5 ]

1.2 Násobenie obdĺžnikových matíc

A = [ 1 2 3 ]       B = [ 1 0 ]
    [ 0 1 4 ]           [ 2 1 ]
                        [ 0 2 ]
Urči rozmery AB a vypočítaj ho.
Postup a riešenie

A je 2×3, B je 3×2, takže AB existuje a je 2×2. Vypočítame všetky štyri prvky:

(AB)₁₁ = 1·1+2·2+3·0 = 5
(AB)₁₂ = 1·0+2·1+3·2 = 8
(AB)₂₁ = 0·1+1·2+4·0 = 2
(AB)₂₂ = 0·0+1·1+4·2 = 9
AB = [ 5 8; 2 9 ].

BA tiež existuje, ale má rozmer 3×3. Už podľa rozmeru vidno, že AB a BA nemôžu byť rovnaké.

1.3 Maticová rovnica

2A+3X=B, kde A=[1 2; 0 1], B=[5 4; 3 2]. Urči X.
Postup a riešenie
3X = B−2A = [5 4; 3 2] − [2 4; 0 2] = [3 0; 3 0]
X = ⅓[3 0; 3 0] = [1 0; 1 0].

Kontrola: 2A+3X=[2 4;0 2]+[3 0;3 0]=B.

1.4 Skús sám: násobenie

A=[1 2; 3 4], B=[2 1; 0 −1]. Vypočítaj AB aj BA.
Postup a riešenie
AB=[1·2+2·0   1·1+2·(−1); 3·2+4·0   3·1+4·(−1)]
AB=[2 −1; 6 −1].
BA=[2·1+1·3   2·2+1·4; 0·1+(−1)·3   0·2+(−1)·4]
BA=[5 8; −3 −4].

2. Determinant, inverzia a hodnosť

Pre 2×2: det[a b;c d]=ad−bc. Pre 3×3 možno rozvíjať podľa prvého riadka so znamienkami + − +. Inverzia existuje, práve keď determinant štvorcovej matice nie je nula.

2.1 Determinant 3×3

A=[1 2 0; 0 1 1; 2 0 1]. Vypočítaj det A.
Postup a riešenie
det A = 1·det[1 1;0 1] − 2·det[0 1;2 1] + 0·det[0 1;2 0]
      = 1·(1·1−1·0) − 2·(0·1−1·2)
      = 1 − 2·(−2) = 5.

Pri mínuse pred druhým členom pozorne sleduj znamienka.

2.2 Determinant elimináciou

A=[1 2 1; 2 5 3; 1 0 8].
Postup a riešenie
R₂ ← R₂−2R₁, R₃ ← R₃−R₁:
[1 2 1; 0 1 1; 0 −2 7]
R₃ ← R₃+2R₂:
[1 2 1; 0 1 1; 0 0 9]
det A=1·1·9=9.

Použili sme len pripočítanie násobku iného riadka, ktoré nemení determinant. Výmena riadkov by zmenila znamienko; vynásobenie riadka číslom k by vynásobilo determinant číslom k.

2.3 Inverzná matica pomocou Gauss–Jordanovej metódy

A=[1 2; 3 7]. Nájdite A⁻¹.
Postup a riešenie
[A | I] = [1 2 | 1 0; 3 7 | 0 1]
R₂ ← R₂−3R₁: [1 2 | 1 0; 0 1 | −3 1]
R₁ ← R₁−2R₂: [1 0 | 7 −2; 0 1 | −3 1]
A⁻¹=[7 −2; −3 1].

Kontrola: det A=7−6=1 a AA⁻¹=[1 0;0 1]. Každá riadková úprava sa robí na celej rozšírenej matici.

2.4 Hodnosť matice

A=[1 2 3; 2 4 6; 1 1 1]. Urči h(A).
Postup a riešenie
R₂ ← R₂−2R₁: [1 2 3; 0 0 0; 1 1 1]
R₃ ← R₃−R₁:  [1 2 3; 0 0 0; 0 −1 −2]
Prehodíme posledné dva riadky: [1 2 3; 0 −1 −2; 0 0 0].
Máme dva pivoty → h(A)=2.

2.5 Skús sám: inverzia

Nájdi inverziu B=[2 1; 5 3] a over BB⁻¹=I.
Postup a riešenie
det B=2·3−1·5=1 ≠ 0.
B⁻¹=[3 −1; −5 2].
BB⁻¹=[6−5  −2+2; 15−15  −5+6]=[1 0;0 1].

3. Sústavy lineárnych rovníc

3.1 Gaussova eliminácia s tromi neznámymi

x+y+z=6
2x+y−z=1
x−y+z=2
Postup a riešenie
[1  1  1 | 6; 2 1 −1 | 1; 1 −1 1 | 2]
R₂ ← R₂−2R₁; R₃ ← R₃−R₁:
[1 1 1 | 6; 0 −1 −3 | −11; 0 −2 0 | −4]
R₃ ← R₃−2R₂:
[1 1 1 | 6; 0 −1 −3 | −11; 0 0 6 | 18]
6z=18 → z=3; −y−3z=−11 → y=2; x=6−2−3=1.

Kontrola: 1+2+3=6; 2+2−3=1; 1−2+3=2.

3.2 Žiadne alebo nekonečne veľa riešení?

a) x+y=2; 2x+2y=5.
b) x+y=2; 2x+2y=4.
Postup a riešenie
a) R₂←R₂−2R₁ → [0 0 | 1], čiže 0=1. Žiadne riešenie.
b) R₂←R₂−2R₁ → [0 0 | 0]. Zvoľ y=t, potom x=2−t.
Riešenia: (x,y)=(2−t,t), t∈ℝ; je ich nekonečne veľa.

Frobeniova veta: v a) sú hodnosti A a [A|b] rôzne; v b) sú rovnaké a menšie ako počet neznámych.

3.3 Homogénna sústava

x+y+z=0; 2x+y+3z=0.
Postup a riešenie
R₂←R₂−2R₁ → −y+z=0 → y=z.
Zvoľ z=t. Potom y=t a x=−2t.
(x,y,z)=t(−2,1,1), t∈ℝ.

Pre t=0 dostaneme nulové riešenie; pre t≠0 nenulové riešenia.

3.4 Cramerovo pravidlo

2x+y=5; x−y=1.
Postup a riešenie
A=[2 1;1 −1]; det A=−2−1=−3.
A₁=[5 1;1 −1]; det A₁=−5−1=−6 → x=(−6)/(−3)=2.
A₂=[2 5;1 1]; det A₂=2−5=−3 → y=(−3)/(−3)=1.

Pravidlo môžeme použiť, pretože sústava je štvorcová a det A≠0.

4. Vektorové priestory

4.1 Závislosť vektorov

v₁=(1,1,0), v₂=(0,1,1), v₃=(1,2,1). Sú nezávislé?
Postup a riešenie
Hľadáme a,b,c: av₁+bv₂+cv₃=0.
Po súradniciach: a+c=0; a+b+2c=0; b+c=0.
Zvoľ c=1 → a=−1, b=−1. Stredná rovnica platí.
−v₁−v₂+v₃=0 s nenulovými koeficientmi → vektory sú závislé.

Rovnako vidno v₃=v₁+v₂. Vektory v₁ a v₂ sú nezávislé, preto tvoria bázu ich obalu s dimenziou 2.

4.2 Súradnice v báze

B=((1,1),(1,−1)), v=(5,1). Urči [v]ᵦ.
Postup a riešenie
Hľadáme α,β: α(1,1)+β(1,−1)=(5,1).
α+β=5; α−β=1 → 2α=6 → α=3; β=2.
[v]ᵦ=(3,2).

Kontrola: 3(1,1)+2(1,−1)=(5,1). Poradie bázových vektorov určuje poradie súradníc.

4.3 Test podpriestoru

Je U={(x,y,z)∈ℝ³ : x+y−z=0} podpriestor?
Postup a riešenie

Nula patrí do U. Ak u aj v spĺňajú rovnicu, ich súčet ju spĺňa tiež, lebo súčet dvoch núl je nula. Pre ľubovoľný skalár c ju spĺňa aj cu. Preto U je podpriestor.

Z rovnice z=x+y: (x,y,z)=x(1,0,1)+y(0,1,1).
Tieto dva vektory sú nezávislé, takže tvoria bázu U; dim U=2.

5. Relácie a zobrazenia

5.1 Vlastnosti relácie

A={a,b,c}, R={(a,a),(b,b),(c,c),(a,b),(b,c)}.
Urči reflexivitu, symetriu, antisymetriu a tranzitivitu.
Postup a riešenie

Reflexívna: áno, všetky diagonálne dvojice sú v R. Symetrická: nie, (a,b) je v R, ale (b,a) chýba. Antisymetrická: áno, pre žiadne dva rôzne prvky neobsahuje obe opačné dvojice. Tranzitívna: nie, (a,b) a (b,c) sú v R, ale (a,c) chýba. Preto nie je ani ekvivalenciou, ani usporiadaním.

5.2 Zobrazenie a jeho typ

X={1,2,3,4}, Y={a,b,c}; f={(1,b),(2,c),(3,a),(4,a)}.
Postup a riešenie

Každý vstup má presne jeden obraz, takže ide o zobrazenie. Každý prvok Y sa vyskytne ako obraz, preto je surjektívne. Nie je injektívne: f(3)=f(4)=a. Nie je bijektívne.

6. Algebraické štruktúry

6.1 Operácia s jedným predpisom

Na ℝ definuj x★y=x+y+1. Urči vlastnosti (ℝ,★).
Postup a riešenie
Uzavretosť: x+y+1∈ℝ.
Komutativita: x+y+1=y+x+1.
Asociativita: (x★y)★z=x+y+z+2=x★(y★z).
Neutrálny prvok e: x+e+1=x → e=−1.
Inverzia y k x: x+y+1=−1 → y=−x−2.
Záver: abelovská grupa.

Kontrola pre x=3: 3★(−5)=−1, čo je neutrálny prvok.

6.2 Dve operácie zo staršieho vzorového testu

x⊕y=x+y+½,  x⊙y=x+y+2xy na ℝ.
Postup a riešenie
Neutrálny prvok pre ⊕: x+e+½=x → e=−½.
Inverzný prvok k x pre ⊕: x+y+½=−½ → y=−x−1.
Jednotka pre ⊙: x+e+2xe=x → e=0.
Inverzia pre ⊙: x+y+2xy=0 → y=−x/(1+2x), ak x≠−½.

Na dôkaz zvyšných vlastností použi bijekciu φ(x)=2x+1. Platí φ(x⊕y)=φ(x)+φ(y) a φ(x⊙y)=φ(x)φ(y). Operácie teda zodpovedajú obvyklým operáciám na ℝ, takže ide o komutatívne teleso. Výnimka pri násobnej inverzii je −½, teda neutrálny prvok prvej operácie.

7. Zmiešaný skúšobný test

Skús bez nápovedy. Čas si stanov podľa informácií od vyučujúceho; tento test nie je oficiálne zadanie ani odhad bodovania.

  1. Vypočítaj AB pre A=[1 2;0 1], B=[2 0;3 1].
  2. Urči determinant a inverznú maticu C=[1 2;2 5].
  3. Vyrieš x+y+z=6, 2x+y−z=1, x−y+z=2.
  4. Sú (1,1,0), (0,1,1), (1,2,1) nezávislé?
  5. Na A={1,2,3} posúď tranzitivitu R={(1,2),(2,3)}.
  6. Na ℤ₄ over, či je 2 deliteľom nuly.
Výsledky a stručná kontrola
  1. AB=[8 2;3 1].
  2. det C=1; C⁻¹=[5 −2;−2 1].
  3. (x,y,z)=(1,2,3).
  4. Nie: v₃=v₁+v₂.
  5. Nie: chýba (1,3).
  6. Áno: 2≠0 a 2·2=0 modulo 4.
